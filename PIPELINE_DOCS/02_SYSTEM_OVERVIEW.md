# System Overview

## 🦞 OpenClaw Configuration

The entire pipeline runs on the **OpenClaw** multi-agent framework. The central configuration file is located at `~/.openclaw/openclaw.json`.

### Agent Registration
Inside `openclaw.json`, we have explicitly registered 5 agents, assigning each its own isolated workspace directory. This isolation ensures that files generated by the Writer don't accidentally pollute the Researcher's logic.

```json
"list": [
  { "id": "orchestrator", "workspace": "/home/bhard/.openclaw/workspace-orchestrator" },
  { "id": "researcher",   "workspace": "/home/bhard/.openclaw/workspace-researcher" },
  { "id": "writer",       "workspace": "/home/bhard/.openclaw/workspace-writer" },
  { "id": "creator",      "workspace": "/home/bhard/.openclaw/workspace-creator" },
  { "id": "publisher",    "workspace": "/home/bhard/.openclaw/workspace-publisher" }
]
```

### The LLM Provider
OpenClaw is configured to use **OpenRouter** as the backend LLM provider (specifically routing to `google/gemini-2.5-pro` or similar models).
- The API key is injected via the environment variable: `export OPENROUTER_API_KEY="..."`

## 🔐 Security & Permissions (`exec-approvals.json`)

By default, OpenClaw agents operate in a sandbox and are not allowed to execute raw shell commands. Because our pipeline requires native Linux tools (`curl`, `pandoc`, `gog`, file manipulation), we had to explicitly whitelist these commands.

The permissions are stored in `~/.openclaw/exec-approvals.json`.

**Key Whitelisted Commands:**
1. **`openclaw`**: The Orchestrator MUST be able to run `openclaw agent ...` to spawn the sub-agents.
2. **`rm`**: The Orchestrator MUST be able to delete `sessions.json` files.
3. **`curl` & `sleep`**: The Researcher and Creator need this to hit RSS feeds and the Leonardo API.
4. **`pandoc`, `printf`, `cat`, `cp`**: The Orchestrator and Publisher need these to format Markdown and compile the `.docx` file.
5. **`gog`**: The Publisher needs this to interface securely with Google Drive.

*Note: If you ever add a new tool (e.g., `jq` for JSON parsing), you must manually run it once and approve it in OpenClaw, or manually add it to `exec-approvals.json`.*

## 🔑 Authentication Secrets
- **OpenRouter API Key**: Stored in the shell environment (`OPENROUTER_API_KEY`).
- **Leonardo AI API Key**: Stored in the shell environment (`LEONARDO_API_KEY`).
- **Google Drive Auth**: Authenticated via the `gog` CLI. Because OpenClaw runs non-interactively, bypass the keyring password prompt by prepending `GOG_KEYRING_PASSWORD="YOUR_GOG_KEYRING_PASSWORD"` to every `gog` command.
