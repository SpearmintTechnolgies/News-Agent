# /top5

This is a dedicated production command.

It is NOT general conversation.

When `/top5` is invoked, execute only this workflow.

---

# ABSOLUTE COST TARGET

Use the minimum possible model work.

Use:

- Gemini 2.5 Flash
- low reasoning
- ONE web search
- ONE Gemini response
- ONE terminal execution
- FIVE local FLUX image generations
- ZERO Hermes image_generate calls
- ZERO subagents
- ZERO WordPress
- ZERO browser automation
- ZERO repeated research
- ZERO repeated image generation

The local FLUX image generations happen outside the LLM through:

~/.hermes/scripts/top5_pipeline.py

Do not call image_generate.

---

# RESEARCH

Perform ONE broad web search for current important crypto/blockchain news.

Use search-result snippets first.

Select exactly five distinct stories.

Prioritize:

1. major market-moving events
2. major crypto companies/exchanges
3. important blockchain developments
4. regulation/policy
5. major security incidents
6. important ecosystem developments

Do not select five stories about the same event.

Do not fetch full articles unless absolutely necessary.

Use only the minimum evidence needed to establish:

- what happened
- important numbers
- important names
- why it matters
- source URL

---

# ONE GEMINI RESPONSE

After the single research pass, prepare ALL FIVE stories together.

Do not perform a separate writing workflow for every story.

Do not produce a long visible answer.

Create exactly this JSON payload:

{
  "project": "<project-slug-from-group>",
  "stories": [
    {
      "headline": "<short factual headline>",
      "summary": "<2 concise sentences>",
      "category": "<category>",
      "asset": "<asset or N/A>",
      "tags": ["tag1", "tag2", "tag3"],
      "source_url": "https://...",
      "visual_prompt": "<35–55 word visual description>"
    }
  ]
}

Rules:

- exactly 5 stories
- exactly 5 objects
- real HTTPS source URLs
- no invented information
- no duplicate stories
- headline maximum 10 words
- summary maximum 2 short sentences
- visual_prompt 35–55 words
- visual_prompt must describe the specific news event
- never write article-length content

---

# VISUAL PROMPT

The visual prompt must be specific to the story.

Describe:

- exact subject
- exact event
- important visual object
- 2–4 concrete visual elements
- strong central composition
- editorial framing
- appropriate mood
- cinematic lighting
- premium financial-news aesthetic
- mobile-friendly composition

Do NOT include headline text in the visual prompt.

Do NOT ask FLUX to render any text.

The local pipeline will add the exact headline after FLUX generation.

The local pipeline also adds the exact MemeCoinist logo.

---

# FLUX IMAGE RULES

Each of the five stories gets exactly ONE image.

The local pipeline uses:

Model:
FLUX.2 Klein 9B

Resolution:
512×512

Steps:
4

Guidance:
1.0

Images:
1 per story

The image should be visual only.

NO AI text.
NO AI logo.
NO AI watermark.

The image should leave a clean, slightly darker, uncluttered top-left area for the MemeCoinist logo.

---

# PERFECT TEXT

The exact headline is NOT generated by FLUX.

After FLUX creates the artwork, the local pipeline places:

1. the exact MemeCoinist logo
2. the exact headline

using deterministic image compositing.

Therefore:

- spelling is exact
- wording is exact
- punctuation is exact
- alignment is controlled
- font is controlled
- line wrapping is controlled
- no gibberish
- no random letters
- no distorted text

Use one strong headline only.

Maximum:
10 words.

---

# TELEGRAM DELIVERY

The terminal pipeline sends each story independently.

IMPORTANT:

Do NOT wait for all five images before sending.

The pipeline does:

Story 1:
generate → brand → send photo + Story 1 caption

then:

Story 2:
generate → brand → send photo + Story 2 caption

then:

Story 3

then:

Story 4

then:

Story 5

Each image is therefore paired with ONLY its own news story.

Do NOT send a bulk media group.

Do NOT send all five images in one final response.

---

# CAPTION FORMAT

Each Telegram photo uses its matching caption:

**Headline**

2 concise sentences.

**Category:** ...
**Asset:** ... | **Tags:** ...

Source: https://...

No long explanations.

No image URLs.

---

# TERMINAL EXECUTION

After creating the JSON payload, make ONE terminal call.

The terminal command must:

1. write the JSON payload to a temporary file
2. run:

python3 ~/.hermes/scripts/top5_pipeline.py /tmp/top5_payload.json

3. remove the temporary file

Do not make multiple terminal calls.

Do not run image generation yourself.

The script handles all five images and all Telegram deliveries.

---

# FINAL RESPONSE

After the terminal pipeline succeeds, respond with exactly:

[SILENT]

Do not send another text message.

The five photo messages created by the pipeline are the complete `/top5` response.

If the pipeline reports a failure, do not retry image generation repeatedly.
