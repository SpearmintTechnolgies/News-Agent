# COINOGRAPHY_TEMPLATE.md

**Authoritative template:** `workspace-writer/COINOGRAPHY_TEMPLATE.md` (writer agent reads that file).

**Formatting Rules for Crypto News Articles**

- **In-body source links:** Max **2** markdown anchors to `source_urls` (distinct URLs; hook or first H2 only). No x.com or twitter.com links in the body.
- **Title**: One line, title case, include primary crypto asset if possible.
- **Subtitle** (optional): One sentence, summarises angle.
- **Lead Paragraph**: Hook, 2-3 sentences, includes the main news event.
- **Body**: 3-5 sections, each with a heading. Provide facts, context, quotes, impact.
- **Conclusion**: Summarise implications, future outlook.
- **Sources**: List each source on its own line, prefixed with a hyphen.
- **Word Count**: At the very end, on a line by itself, write `Word Count: <number>`.

**Stylistic Guidelines**
- Use active voice, present tense where appropriate.
- Keep sentences concise (≤25 words).
- Avoid jargon; explain technical terms.
- Maintain neutral tone; disclose any speculation.

**Length**: Target 1100‑1200 words total.
